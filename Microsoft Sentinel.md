**Microsoft Sentinel** is a cloud-native **SIEM** (Security Information and Event Management) and **SOAR** (Security Orchestration, Automation, and Response) service that runs on Azure.

In plainer terms: it collects security data, helps you detect threats, investigates what happened, and can automate the response.

### What it does
Think of it as the command center for security operations.

**Collect**
- Ingests logs from Azure resources, on-prem servers, firewalls, endpoints, SaaS apps, etc.
- Uses built-in connectors and supports custom data sources.

**Detect**
- Analytics rules, threat intelligence, and behavior models find suspicious activity.
- Can use machine learning to reduce noise.

**Investigate**
- Incidents are grouped, mapped on timelines, and enriched with context.
- Hunting queries let analysts search across massive datasets.

**Respond**
- Playbooks (Logic Apps) automate tasks like isolating a machine, disabling an account, or notifying teams.

### Why teams like it
- No infrastructure to maintain.
- Scales fast.
- Integrates deeply with Microsoft security tools (Defender, Entra ID, etc.).
- Strong automation capabilities.

### Common real-world uses
Security teams use it to:
- Detect compromised accounts  
- Investigate phishing  
- Monitor privileged access  
- Track lateral movement  
- Centralize logs for compliance

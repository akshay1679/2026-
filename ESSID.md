
**ESSID** stands for **Extended Service Set Identifier**.

In simple terms, it’s the **name of a Wi-Fi network** that you see when you search for available wireless connections.

---

### 🔎 What Does It Mean?

- **SSID (Service Set Identifier)** → The name of a single Wi-Fi network.
    
- **ESSID (Extended Service Set Identifier)** → Essentially the same thing, but used when multiple access points share the same network name to create a larger wireless network.
    

Today, **ESSID and SSID are often used interchangeably**.

---

### 📶 Example

If you open your phone’s Wi-Fi settings and see:

- `Home_WiFi`
    
- `CoffeeShop_Free_WiFi`
    
- `OfficeNet`
    

Those names are ESSIDs (or SSIDs).

---

### 🧠 Why “Extended”?

An **Extended Service Set (ESS)** is when:

- Multiple wireless routers or access points
    
- Share the same network name (ESSID)
    
- So devices can roam between them without disconnecting
    

This is common in:

- Large homes
    
- Offices
    
- Hotels
    
- Campuses
    

---

### ⚙️ Where You See ESSID

- On your router’s configuration page
    
- In Wi-Fi scanning tools (like `iwconfig` in Linux)
    
- In network security tools

Shodan continuously scans the internet and collects:

- IP addresses
- Open ports
- Running services (HTTP, FTP, SSH, etc.)
- Server banners (software version info)
- Device type and sometimes location

For example, you can search for:

- `apache 2.4.49`
- `port:22 country:US`
- `webcam`
- `mongodb port:27017`

### Uses

Security professionals use Shodan to:

- Find exposed servers
- Identify vulnerable devices
- Monitor their organization’s attack surface
- Detect misconfigured systems


## Network segmentation

**Class network segmentation** refers to dividing a computer network into smaller parts (segments) based on **IP address classes (Class A, B, C, etc.)** to organize traffic, improve performance, and enhance security.

It comes from the older **classful IP addressing system**, which grouped IP addresses into predefined classes.

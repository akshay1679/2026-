**Heuristic / anomaly-based detection** is a way security systems find threats by spotting behavior that **deviates from what’s considered normal**, rather than matching a known attack signature.

In short:

- **Heuristic** → uses rules, patterns, or educated guesses (e.g., “program trying to modify system files + hide itself = suspicious”).
    
- **Anomaly-based** → builds a baseline of normal activity, then flags unusual actions (e.g., a user downloading 10× more data than usual).
    

✅ Good at catching **new or unknown attacks**  
⚠️ Can produce **false positives** if unusual ≠ malicious

1. **Price Manipulation**
    
    1. User changes the price in the request before payment.
    2. Server does not verify price → item purchased for $1 instead of $100.
        
2. **Bypassing Steps**
    
    1. User directly accesses `/payment-success` URL without paying.
        
3. **Unlimited Coupon Use**
    
    1. App doesn’t limit coupon reuse.
    2. Attacker uses same discount code repeatedly.
        
4. **Negative Quantity Attack**
    
    1. User sets quantity to `-1`
    2. System refunds money instead of charging.

🔎 Your Main Command

You ran:

`nmap 192.168.140.133 -p 21 -sV --script ftp* -oX metaFTP`

Meaning:

`-p 21` → Scan only FTP port

`-sV` → Detect service version

`--script ftp*` → Run all FTP-related NSE scripts

`-oX metaFTP` → Output results in XML format



---

⚠️ The Error You Got

NSE: [ftp-bounce] Couldn't resolve scanme.nmap.org
NSE: [ftp-bounce] 500 Illegal PORT command

Why This Happens

1️⃣ ftp-bounce script behavior

The ftp-bounce script attempts an FTP bounce attack test.
It tries to connect to:

scanme.nmap.org

If:

You have no internet access

DNS is not resolving

The target FTP server blocks PORT command


You will see:

500 Illegal PORT command

This is normal behavior in many FTP servers.

Metasploitable often:

Allows some vulnerable scripts

Blocks some FTP bounce attempts



---

✅ How To Fix / Improve Your Scan

🔹 If you want to avoid ftp-bounce errors:

Run only safe FTP scripts:

nmap 192.168.140.133 -p 21 -sV --script "ftp-anon,ftp-syst,ftp-vsftpd-backdoor"

🔹 If you want ALL FTP scripts but no internet dependency:

Disable external DNS resolution:

nmap 192.168.140.133 -p 21 -sV --script ftp* --script-args=newtargets

🎯 Metasploitable 2

🎯 vsftpd

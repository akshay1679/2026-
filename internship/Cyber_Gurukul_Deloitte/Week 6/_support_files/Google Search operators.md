Here is a **complete, organized list of Google Search operators** .

---

### 🔎 1️⃣ Core Search Operators (Working)

## 📌 `intitle:`

Find pages with a word in the title.

```
intitle:marketing
```

## 📌 `allintitle:`

All words must appear in the title.

```
allintitle:digital marketing strategy
```

## 📌 `inurl:`

Find pages with a word in the URL.

```
inurl:blog
```

## 📌 `allinurl:`

All words must appear in the URL.

```
allinurl:seo tools
```

## 📌 `intext:`

Find pages containing a word in the body text.

```
intext:"artificial intelligence"
```

## 📌 `allintext:`

All words must appear in body text.

```
allintext:machine learning tutorial
```

## 📌 `site:`

Search within a specific website or domain.

```
site:nytimes.com AI
```

## 📌 `filetype:` (or `ext:`)

Find specific file types.

```
filetype:pdf resume
```

## 📌 `related:`

Find similar websites.

```
related:amazon.com
```

## 📌 `cache:`

View Google's cached version.

```
cache:example.com
```

---

# 🔎 2️⃣ Basic Search Symbols

## 📌 `" "` (Quotes)

Exact match.

```
"best SEO tools"
```

## 📌 `-` (Minus)

Exclude words.

```
apple -fruit
```

## 📌 `OR`

Search for either term.

```
marketing OR advertising
```

## 📌 `*` (Wildcard)

Acts as placeholder inside quotes.

```
"best * tools"
```

## 📌 `()` (Grouping)

Group terms.

```
(digital OR content) marketing
```

# 🔎 3️⃣ Number & Range Operators

## 📌 `..` (Range)

Number range.

```
laptop $500..$1000
```

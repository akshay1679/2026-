## 🌐 Netcraft for Open Source Intelligence (OSINT)

**Netcraft** is widely used in **OSINT investigations** to collect publicly available information about websites, domains, and infrastructure.

---

# 🔎 How Netcraft is Used in OSINT

### 1️⃣ Domain & Hosting Intelligence

You can discover:

- Hosting provider (AWS, DigitalOcean, etc.
- IP address of the server
- Server location (country)
- Web server software (Apache, Nginx, IIS)


👉 Helps identify where a website is hosted.

---

### 2️⃣ DNS & Subdomain Enumeration

Netcraft allows you to:

- Find subdomains
- View nameservers
- Check domain registrar
- Track DNS history

👉 Useful for mapping an organization’s <mark style="background: #ABF7F7A6;">digital footprint</mark>.

---

### 3️⃣ SSL Certificate Analysis

It shows:

- SSL certificate issuer
- Validity period
- Associated domains (via certificate reuse)

👉 Can uncover related domains owned by the same organization.

---

### 4️⃣ Hosting History Tracking

Netcraft provides:

- Historical hosting data
- Previous IP addresses
- Past technologies used

👉 Very useful in investigations to see infrastructure changes.

---

### 5️⃣ Phishing & Fraud Detection

- Detect suspicious domains
- Check website reputation
- Identify phishing infrastructure

---

# 🎯 Why It’s Important in OSINT

Netcraft helps investigators:

- Attribute infrastructure
- Identify attack surfaces
- Detect fake websites
- Link related domains
- Understand technology stack

---

# 🧠 Example OSINT Scenario

Suppose you're investigating a suspicious website:

1. Check hosting provider
2. Look at SSL certificate for related domains
3. Identify subdomains
4. Compare hosting history

This builds a profile without directly attacking the system.

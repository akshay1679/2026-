The **Log4Shell** vulnerability is a critical security flaw found in the widely used Java logging library **Apache Log4j**, affecting versions 2.0 through 2.14.1. Discovered in December 2021, it allows attackers to perform remote code execution (RCE) by injecting specially crafted strings (such as `${jndi:ldap://...}`) into application logs, which Log4j processes using its JNDI lookup feature. This can cause the application to fetch and execute malicious code from an attacker-controlled server without authentication. The vulnerability is particularly dangerous because it is easy to exploit and impacts a vast number of Java applications. To mitigate the risk, organizations should upgrade to Log4j version 2.17.x or later, or apply temporary fixes such as disabling JNDI lookups or removing the JndiLookup class from the library.

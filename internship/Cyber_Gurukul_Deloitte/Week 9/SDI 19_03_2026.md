## See all executed commands

to see all the executed commands inside the computer `"computer" : "MSEDGEWIN10"` 

```
source="sysmon-events.json" "Computer": "MSEDGEWIN10" | stats count by Event.EventData.CommandLine
```

## Search suspicious keywords

```
source="sysmon-events.json" updater
```

```
source="sysmon-events.json" | search updater
```

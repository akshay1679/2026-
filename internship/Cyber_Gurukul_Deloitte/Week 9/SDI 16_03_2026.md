## Install Splunk Enterprise (Windows 11)

### WHY?

Splunk Enterprise acts as the **central server that collects and analyzes logs**.

Open Splunk in browser:

```
http://localhost:8000
```

Login with the admin account.

You should see **Splunk Dashboard**.

---

## 1️⃣ Find Windows 11 IP Address (Splunk Server)

On **Windows 11 (Host)** open CMD:

ipconfig

Find something like:

```
IPv4 Address : 192.168.1.50
```

<mark style="background: #ABF7F7A6;">Save this.
</mark>
Example:

```
Splunk Server IP = 192.168.1.50
```

On **Windows 11 Splunk Enterprise UI**

Open browser:

# 3️⃣ Allow Firewall on Windows 11

Open **PowerShell as Administrator**:

```
New-NetFirewallRule -DisplayName "SplunkForwarderPort" -Direction Inbound -Protocol TCP -LocalPort 9997 -Action Allow
```

# 5️⃣ Configure Windows 10 Universal Forwarder

Open **Command Prompt (Admin)** in Windows 10 VM.

Go to Splunk Forwarder directory:

```
cd "C:\Program Files\SplunkUniversalForwarder\bin"
```

Connect forwarder to server:

```
splunk add forward-server 10.176.45.183:9997
```

Enter admin credentials.

# STEP 6 — Tell the Forwarder What Logs to Send

### WHY?

The forwarder is connected but **does not know which logs to collect**.

We configure **Windows Event Logs**.

Go to this folder:

```
cd "C:\Program Files\SplunkUniversalForwarder\etc\system\local"
```

Create file:

```
inputs.conf
```

==to create a file using `cmd` ==

```
type nul > inputs.conf
```

Open it and paste:

```
[WinEventLog://System]  
disabled = 0  
  
[WinEventLog://Security]  
disabled = 0  
  
[WinEventLog://Application]  
disabled = 0
```
Save.


![[Pasted image 20260317092632.png]]

==to input to the `inputs.conf` directly ==

```
(
echo [WinEventLog://System]
echo disabled = 0
echo.
echo [WinEventLog://Security]
echo disabled = 0
echo.
echo [WinEventLog://Application]
echo disabled = 0
) > inputs.conf
```

==to check== `type` is a similar command like cat in Linux

```
type inputs.conf
```

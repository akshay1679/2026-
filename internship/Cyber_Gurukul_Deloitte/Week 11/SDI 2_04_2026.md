## What is **Ansible**

**Ansible** is a tool used to **automate tasks on other computers over a network**.
Ansible = automation tool for managing and configuring multiple systems remotely

## How it works (your case):

- Your **Ubuntu machine** → acts as the **<mark style="background: #ABF7F7A6;">control node</mark>** (where Ansible is installed)
- Your **Kali Linux machine** → acts as the **<mark style="background: #ABF7F7A6;">managed node</mark>**
- Connection happens via **<mark style="background: #ADCCFFA6;">SSH</mark> (no agent needed)**

we are trying to connect with ssh so by default in kali the ssh will be disabled so we have to enable it

[[Enable SSH on the Kali Machine]]

![[Pasted image 20260407100751.png]]

in kali we need to create a new user

```
nano NewUser.yml
```

then paste

```
---
-  hosts: kali
  become: true
  vars:
    created_username: lucy

  tasks:
    - name: Install aptitude
      apt:
        name: aptitude
        state: latest
        update_cache: true

    - name: Setup passwordless sudo
      lineinfile:
        path: /etc/sudoers
        state: present
        regexp: '^%sudo'
        line: '%sudo ALL=(ALL) NOPASSWD: ALL'
        validate: '/usr/sbin/visudo -cf %s'

    - name: Create a new regular user with sudo privileges
      user:
        name: "{{ created_username }}"
        state: present
        groups: sudo
        append: true
        create_home: true

    - name: Set authorized key for remote user
      ansible.posix.authorized_key:
        user: "{{ created_username }}"
        state: present
        key: "{{ lookup('file',   '/root/.ssh/id_rsa.pub) }}"
```

## 🔹 What Is a **Macro Function**?

A **macro function** is a small program written inside software (like word processors or spreadsheets) to automate repetitive tasks.

For example:

- In **Microsoft Excel**, a macro can automatically format tables.
    
- In **Microsoft Word**, a macro can auto-insert headers, footers, or perform repeated formatting.
    

Macros are usually written in a scripting language like **VBA (Visual Basic for Applications)**.

### ✅ Simple Example:

Instead of manually formatting 100 rows in Excel, you record a macro once — and it does the job instantly every time.

So, a macro function = **automation tool inside applications**.

---

## 🔹 What Is a **Macro Virus**?

A **macro virus** is a type of computer virus written using macro language (like VBA) that infects documents.

It hides inside files such as:

- Word documents (.doc, .docm)
    
- Excel spreadsheets (.xls, .xlsm)
    

When the file is opened and macros are enabled, the virus runs automatically.

### ⚠️ What Can a Macro Virus Do?

- Delete or modify files
    
- Spread to other documents
    
- Steal information
    
- Send infected files to others via email
    

---

## 🔍 Difference Between Macro Function & Macro Virus

|Macro Function|Macro Virus|
|---|---|
|Helpful automation tool|Malicious program|
|Saves time|Damages system|
|Created intentionally by user|Created by hackers|
|Safe when used properly|Dangerous|

---

## 🛡️ How to Stay Safe from Macro Viruses

- Don’t enable macros in unknown documents
    
- Download files only from trusted sources
    
- Use antivirus software
    
- Keep Microsoft Office updated

### Maltego (in short, in points)

- 🔎 **OSINT Tool** – Used to collect publicly available information from the internet.
    
- 🌐 **Relationship Mapping** – Shows connections between people, domains, emails, IPs, and organizations using graphs.
    
- 🕵️ **Reconnaissance Tool** – Helps ethical hackers gather data before penetration testing.
    
- 🔗 **Entity-Based Analysis** – Works with entities like domain names, IP addresses, phone numbers, emails, etc.
    
- ⚙️ **Transforms** – Automated queries that pull data from different online sources.
    
- 📊 **Visual Graphs** – Displays results in an interactive graph to easily see relationships.
    
- 🛡️ **Used in Cybersecurity** – Helpful for investigators, security analysts, and ethical hackers.
    

📌 **In simple words:**  
Maltego is a **visual investigation tool that helps find and map relationships between online information.**

The phrase **“<mark style="background: #ADCCFFA6;">single pane of glass</mark>”** is used in tools like **Maltego** to describe a **single interface where you can view and manage all information at once**.

### Why it is called **Single Pane of Glass**

- 🪟 **Single Window View** – All data, results, and relationships are displayed in **one screen/interface**.
    
- 🔎 **Centralized Information** – Information from many sources (domains, IPs, emails, social media) appears in one place.
    
- 🔗 **Connected Visualization** – Relationships between entities are shown together in a **single graph view**.
    
- ⚡ **Easier Investigation** – Analysts don’t need to open many tools or windows.
    
- 📊 **Unified Control** – You can analyze, expand, and manage data from **one dashboard**.
    

### Simple Meaning

**Single Pane of Glass = One interface where everything can be monitored, analyzed, and controlled together.**

📌 **Example:**  
In **Maltego**, you can see **domains, IP addresses, emails, and their relationships in one graph window**, instead of checking each tool separately.

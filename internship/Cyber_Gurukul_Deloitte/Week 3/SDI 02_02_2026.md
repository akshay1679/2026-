## steps of process modeling

1. understand the application
	1. what our application going to perform
	2. who are the users who are going to access it
	3. what type of data our  app is going to handle
2. creating the dataflow diagram
	1. user → login  page → authentication server → database 
	2. external users
	3. processes
	4. data stores
	5. data flow
3. identify the assets
	1. user password
	2. credit card details
	3. application source code
	4. admin access
4. Identify the potential threat
	1. Microsoft threat modelling tool [[STRIDE]]
5. analyze the possible risk
	1. likelihood
	2. impact
6. define the remedies
	1. we can perform the input validation
	2. we can perform the encryption
	3. we can perform the authentication
	4. we can perform the rate limitation
7. documentation and review
	1. track the fixes
	2. review the previously identifies risk

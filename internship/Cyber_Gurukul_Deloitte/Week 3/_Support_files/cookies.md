Cookies (on a computer) are small pieces of data that a website saves in your web browser when you visit it.
Think of them like tiny memory notes a website keeps about you 🍪


What data a cookie usually has
A cookie is basically a small text record with things like:
User ID or session ID
A random code like A9F3X2
Used to recognize you without storing your name
Login / session status
Tells the site “this user is logged in”
Not your password
Preferences
Language (English, Spanish)
Theme (dark mode / light mode)
Location choice (city or country)
Shopping info
Items in your cart
Recently viewed products
Tracking & analytics data
Pages visited
Time spent on site
Ad interactions (especially third-party cookies)

SYSTEM SECURITY PLANNING PROCESS

Operating system hardening

1. **Remove defaults** – change default passwords, disable unused services, close extra ports.
    
2. **Patch the system** – OS + drivers + apps.
    
3. **Add protection layers** – AV, firewall, IDS/IPS.
    
4. **Test it** – vulnerability scans or controlled attacks (red team / penetration testing).



LFI (Local File Inclusion) and RFI (Remote File Inclusion) are web vulnerabilities occurring when applications improperly sanitize user input, allowing attackers to manipulate file paths. LFI exploits local files on the server to execute malicious scripts, while RFI allows loading malicious code from external servers, often leading to full server compromise.

**OTX (Open Threat Exchange)** is a **threat intelligence sharing platform** where security researchers and organizations share information about cyber threats. It is commonly used for:

- Threat intelligence lookup
- Malware indicators
- Endpoint compromise detection
- IOC investigation
- Integration with SIEM/EDR tools


# 1. Main Navigation Menu (Top Bar)

### 1️⃣ Dashboard

Shows overall threat intelligence summary.

**Contains**

- Latest threat pulses
- Trending malware
- Active campaigns
- Indicators observed globally

**Use Case**  
Security analysts monitor **current threats worldwide**.

### 2️⃣ Browse


Here you explore shared threat intelligence.

Sections available:

| Section              | Meaning                            |
| -------------------- | ---------------------------------- |
| **Pulses**           | Collections of threat indicators   |
| **Users**            | Researchers sharing threat intel   |
| **Groups**           | Communities sharing intelligence   |
| **Indicators**       | IPs, hashes, domains, URLs         |
| **Malware Families** | Known malware categories           |
| **Industries**       | Threats targeting specific sectors |
| **Adversaries**      | Known attacker groups              |

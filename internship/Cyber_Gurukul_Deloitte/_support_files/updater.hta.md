**`updater.hta`** is typically a file that uses the **HTA (HTML Application)** format, which is a special type of file supported by Windows.

## ⚠️ Why `updater.hta` can be suspicious
A file named **`updater.hta`** is often **not a legitimate Windows update file**.

Attackers commonly use names like:
- updater.hta  
- update.hta  
- patch.hta  

to make malware look harmless.

### 🚨 It may be malicious if:
- You didn’t install or download it yourself  
- It appeared suddenly on your PC  
- It runs automatically on startup  
- Your antivirus flags it  

HTA files are frequently used in:
- phishing attachments
- fake software updates
- trojans or remote access malware

---

## 🔍 How to check if it’s safe
1. **Check location**
   - Suspicious if found in:
     - `Downloads`
     - `Temp` folders
     - Unknown program folders

2. **Scan it**
   - Use:
     - entity["software","Windows Security","Microsoft Defender antivirus"]  
     - Or upload to VirusTotal (online scanner)

3. **Right-click → Properties**
   - Look for unknown publisher or no signature

---

## 🛑 What you should do
- ❌ **Do NOT open it**
- ❌ Don’t double-click or run it
- ✅ Run a full antivirus scan
- ✅ Delete it if flagged or suspicious
- ✅ Check startup apps (Task Manager → Startup tab)

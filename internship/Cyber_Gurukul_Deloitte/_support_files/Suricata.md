**Suricata** is a network security tool (an IDS/IPS — Intrusion Detection/Prevention System).

👉 It monitors network traffic and raises **alerts** when it detects suspicious activity.


## 🔍 What are **Suricata signatures**?

- A **signature** is like a rule or pattern.
- Each signature has a unique **ID (SID)**.
- Example:  
    “If traffic looks like malware X → raise alert with SID 2024219”

So:

- **Signature = detection rule**
- **Signature ID (SID) = unique number of that rule**

🐀 A **Remote Access Trojan (RAT)** is a type of malware that allows an attacker to **remotely control a victim’s computer** as if they were sitting in front of it.

![[Pasted image 20260414165526.png]]

## 🧩 How it works (basic flow)

1. Victim downloads or runs infected file
2. RAT installs silently in the background
3. It connects to attacker’s **C2 server**
4. Attacker sends commands remotely
5. 💥 Full control of the system


## Popular RAT examples

- **DarkComet**
- **njRAT**
- **NetWire**
- **Quasar RAT**

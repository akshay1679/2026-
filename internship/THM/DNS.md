
# Domain Name System

## TLD (Top-Level Domain) #TLD

akshay.com  --> TLD  is .com

TLD 2 types
1. gTLD --> Generic Top Level
2. ccTLD --> Country Code Top Level Domain

gTLD was meant to tell the user the domain name's purpose
	.org for an organisation, .edu for education
 ccTLD was used for geographical purposes
	  .ca for sites based in Canada

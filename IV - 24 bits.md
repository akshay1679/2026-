**IV = Initialization Vector**

An **Initialization Vector (IV)** is a random (or pseudo-random) value added to the encryption process to ensure:

- The same key doesn’t produce the same ciphertext twice
    
- Different packets produce different keystreams
    

### 📏 24-bit IV means:

- IV length = **24 bits**
    
- That equals **3 bytes**
    
- Possible combinations:

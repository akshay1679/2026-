Here are the most important topics from **Unit 2.1 - Cyber Security Essentials**, summarized in key points:

**1. ICT Devices and Web Fundamentals**

- **Device Categories:**<mark style="background: #FFB8EBA6;"> Information and Communication Technologies</mark> (ICT) encompass devices like PCs, smartphones, networking devices (routers, switches, firewalls), and specialized servers (file, web, database, and email servers).
- **Web Servers and Apps:** Web servers process browser requests to deliver content (like HTML files) using<mark style="background: #FFB8EBA6;"> DNS to translate URLs to IP addresses</mark>. Web applications provide scalable, centrally updated software accessible directly through browsers.

**2. Networking Concepts, Protocols, and Transmission**

- **Frameworks and Topologies:** Network communication is defined by the 7-layer OSI Model (ranging from the Physical Layer to the Application Layer) and structured through topologies like Bus, Star, Mesh, and Ring.
- **Essential Protocols:** Networks rely on languages like <mark style="background: #FFB8EBA6;">TCP/IP</mark> for reliable data delivery<mark style="background: #FFB8EBA6;">, FTP/SFTP </mark>for file transfer, and secure protocols such as <mark style="background: #FFB8EBA6;">SSH</mark> for remote access, <mark style="background: #FFB8EBA6;">TLS/SSL</mark> for encrypted web traffic, and VPNs for secure tunnels.
- **Transmission Media:** Data travels through guided physical cables (Coaxial, Twisted-Pair, Fiber Optic) or unguided wireless signals (Wi-Fi, Bluetooth, Satellite).

**3. Operating System Security Commands**

- **Unix/Linux:** Analysts use commands like `chmod` and `chown` for file permissions, <mark style="background: #FFB8EBA6;">useradd</mark> for user management, and `md5sum` or `sha256sum` to <mark style="background: #FFB8EBA6;">verify file integrity via hashing</mark>.
- **Windows:** Counterpart commands include `icacls` <mark style="background: #FFB8EBA6;">for access control lists,</mark> `net user`<mark style="background: #FFB8EBA6;"> for accounts</mark>, and `certutil` <mark style="background: #FFB8EBA6;">for file hashing</mark>.

**4. Common Security Solutions**

- **Defensive Tools:** Networks are defended using <mark style="background: #FFB8EBA6;">Firewalls (filtering traffic)</mark>, Intrusion Detection/Prevention Systems (IDS/IPS for monitoring and blocking suspicious activity), Web Security Gateways, and Anti-Virus software.
- **Advanced Monitoring:** <mark style="background: #FFB8EBA6;">Endpoint Detection and Response</mark> (EDR) and <mark style="background: #FFB8EBA6;">Security Information and Event Management</mark> (SIEM) systems aggregate logs to provide centralized monitoring and automated responses.

**5. Electronic Evidence and Forensics**

- **Types of Evidence:** Digital investigations rely on collecting documents, network traffic data (log files, packet captures), metadata, and device data.
- **Evidence Locations:** Crucial evidence can be recovered from volatile memory (RAM), hard drives/SSDs, mobile devices, IoT devices, cloud backups, and network devices like routers.

**6. Threats and Unauthorized Access**

- **Attack Vectors:** Attackers use social engineering (<mark style="background: #FFB8EBA6;">phishing, pretexting, tailgating</mark>) and malware (viruses, Trojans, ransomware, spyware) to steal data or disrupt operations.
- **Vulnerabilities:** Organizations also face risks from zero-day attacks, password brute-forcing, physical device theft, and negligent or disgruntled insiders.

**7. Network Troubleshooting and Defence Techniques**

- **Diagnostics:** Analysts use TCP/IP commands to diagnose issues: `ping` (<mark style="background: #FFB8EBA6;">basic connectivity</mark>), `ipconfig`/`ifconfig` (<mark style="background: #FFB8EBA6;">interface status</mark>), `traceroute` (<mark style="background: #FFB8EBA6;">tracing packet paths</mark>), and `netstat` (<mark style="background: #FFB8EBA6;">active network connections</mark>).
- **Layered Defence:** Mitigating these threats requires a combination of strong passwords, Multi-Factor Authentication (MFA), regular software patching, encrypted data (at rest and in transit), and data backups.
- **Bandwidth Management:** Tools like Traffic Shaping and Quality of Service (QoS) ensure critical applications have necessary bandwidth and help prevent network congestion.

**8. IT System Architecture and Design**

- **Blueprint and Structure:** System architecture acts as a blueprint outlining hardware, software, and interfaces, while system design focuses on the specific data models, UI/UX, and algorithms. Well-defined architecture helps integrate security features naturally, as seen in complex systems like E-commerce platforms or Library Management Systems.

Based on **Unit 3.1 - Security Monitoring and Log Management**, here are the most important topics summarized in key points:

**1. Information Assets and System Components**

- **Identification:** The first step in security monitoring is identifying critical assets that require protection, such as endpoints (laptops, mobile devices), servers, network devices (routers, firewalls), and sensitive data.
- **Monitoring Requirements:** Security teams must define monitoring scope (like real-time traffic or user activity), set up criteria for alarms based on severity levels, and establish response protocols.

**2. Log Types and Interpretation Methods**

- **What Logs Are:** Log files record a history of events, transactions, and system activities, capturing critical metadata like timestamps and user information.
- **Interpretation Techniques:** Security analysts use several methods to interpret massive amounts of log data, including:
    - **Pattern Recognition:** Searching for specific suspicious patterns, such as multiple failed login attempts.
    - **Anomaly Detection:** Identifying deviations from normal system baseline behaviors, often using machine learning.
    - **Time Correlation:** Linking events across different systems within a specific timeframe to track a potential attack's progression.
    - **Log Normalization:** Converting logs from various sources into a standard, consistent format for easier searching and filtering.

**3. Log Data Collection Methods**

- Organizations use different methods to gather log data, including **Agentless logging** (devices send logs directly to a server), **Agent-based logging** (using dedicated software installed on the device), **API-based log collection**, and **SNMP traps** (for network management monitoring).

**4. Network Traffic and Telemetry Monitoring**

- **Network Traffic Monitoring:** Tools track data volume, identify bandwidth issues, and detect malicious signatures. Popular NTA (Network Traffic Analysis) tools include Wireshark, Zabbix, Nagios, and PRTG.
- **Telemetry Monitoring:** This is the automated, real-time collection and transmission of data (system logs, network patterns, user behavior) that acts as the "nervous system" for proactive threat detection.

**5. Time Synchronization and Log Timestamping**

- **Criticality:** Synchronizing clocks across all devices in an IT infrastructure is vital for accurate log analysis, event correlation, and digital forensics during investigations.
- **NTP Protocol:** Organizations utilize the Network Time Protocol (NTP) to reference authoritative time sources and maintain consistent timestamps, which is also a strict requirement for many compliance standards.

**6. SIEM Implementation**

- **Security Information and Event Management (SIEM):** SIEM systems act as a centralized hub that aggregates logs from multiple sources (firewalls, servers, user activity) into a single platform.
- **Benefits:** It empowers analysts with real-time threat detection, automated correlation of complex attack patterns, and streamlined compliance reporting.

**7. External Threat Intelligence**

- To stay ahead of evolving threats, analysts integrate external intelligence sources into their monitoring processes. This includes:
    - **CND Vendor Sites:** Databases like MITRE or NIST that track Common Vulnerabilities and Exposures (CVEs).
    - **CERT (Computer Emergency Response Team):** Provides early warning advisories and details on attacker tactics.
    - **SANS Institute:** Offers in-depth technical research and analysis on malware and emerging threats.

Here are the most important topics from **Unit 5.1 - Practices in Security Operations Center (SOC) Management and Threat Response**, summarized in key points:

**1. Stages of Threat Handling** A structured approach is vital for managing security events effectively. The standard stages include:

- **Recording:** Logging event details in a centralized ticketing platform as soon as they are detected.
- **Detection:** Using tools like SIEM, IDS, and antivirus to identify potential malicious activity.
- **Classification & Triage:** Categorizing the event type (e.g., malware, data breach) and assessing its urgency to prioritize response efforts.
- **Investigation:** Deep-diving into network logs and forensic data to determine the root cause and extent of the compromise.
- **Response & Remediation:** Containing the threat (e.g., isolating compromised systems), eradicating it, and restoring affected systems.
- **Post-Incident Analysis:** Reviewing the incident to improve future response procedures and update the knowledge base.

**2. Workflows for Threat Response and Ticketing** To maintain accountability, SOCs follow specific workflows for incident management:

- **Raising and Categorizing Tickets:** Incidents are logged and categorized based on severity and potential impact.
- **Determining Turnaround Time:** Setting maximum acceptable duration times for resolving specific types of incidents.
- **Assigning Personnel:** Routing the ticket to analysts with the appropriate skill level for investigation.
- **Escalation Matrices:** If a ticket remains unresolved within the turnaround time, it is escalated to specialized teams or senior management using predefined hierarchical pathways.
- **Closure:** Validating that the remediation was effective and documenting the lessons learned before closing the ticket.

**3. Importance of a Knowledge Base and SMEs**

- **Knowledge Base:** Maintaining a centralized repository of historical data, known issues, and mitigation strategies accelerates incident response and reduces the mean time to detect (MTTD) and respond (MTTR).
- **Subject Matter Experts (SMEs):** SMEs play a pivotal role in curating this knowledge base, validating information, guiding complex forensic investigations, and mentoring junior analysts.

**4. Continuous Coverage and Compliance**

- **Continuous Monitoring:** Maintaining 24/7 coverage enables early threat detection, rapid incident response, and an adaptive security posture against an evolving threat landscape.
- **Regulatory Frameworks:** Organizations must strictly align their incident response and reporting practices with data protection and security standards like **GDPR**, **HIPAA**, **PCI DSS**, **ISO/IEC 27001**, and the **NIST Cybersecurity Framework**.

**5. Prioritizing Service Requests** Not all alerts carry the same weight. Analysts prioritize service requests based on several factors:

- **Impact on Security Posture:** Requests involving active breaches or vulnerabilities in critical systems are prioritized higher.
- **Urgency and Time Sensitivity:** Active exploitation attempts or tasks with strict regulatory deadlines demand immediate attention.
- **Strategic Importance and Resource Availability:** Balancing the critical business functions affected against the availability of skilled personnel.

**6. Thorough Documentation and Reporting**

- Standardized templates must be used for documenting monitoring results, ticket raising, and ticket closure.
- Consistent documentation ensures transparency, creates reliable audit trails for compliance, evaluates team performance, and fosters seamless communication between SOC analysts, enterprise IT staff, and executives.

**7. Seeking Specialist Assistance** Analysts must recognize when an issue exceeds their technical capabilities. Guidelines for seeking help include identifying complex technical intricacies, problems requiring specialized domain knowledge (like cryptography or advanced forensics), or navigating complex regulatory compliance laws.
